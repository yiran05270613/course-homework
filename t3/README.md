# T3：算法定价与合谋学习版复现

Calvano, Calzolari, Denicolò & Pastorello (2020), *Artificial Intelligence, Algorithmic Pricing, and Collusion*, American Economic Review 110(10):3267–3297. DOI: 10.1257/aer.20190623。

本项目依据本地论文公式独立实现，没有配套作者源代码。核心为两个独立的表格型 Q-learning 定价者，所有报告结果均由模拟产生。原论文表 1 的部分数字只作为标注清楚的参照，不参与算法或参数选择。

## 一键复现

从项目根目录运行；本次验证环境为 macOS Apple Silicon、Python 3.13.2、Apple clang++：

```sh
source .venv/bin/activate
python -m pip install -r t3/requirements.txt
python t3/src/replicate.py
python t3/src/verify.py
```

如果没有虚拟环境，先运行 `python3 -m venv .venv`。需要支持 C++17 的 `clang++` 或 `g++`；macOS 可安装 Apple Command Line Tools，Linux 可安装 g++。首次安装 Python 依赖需要联网；计算、作图和结果浏览均不需要联网。若 Matplotlib 缓存目录不可写，可在命令前设置 `MPLCONFIGDIR=/tmp/t3-matplotlib`。

直接打开 `results/index.html`。它包含中文讲解和内嵌图片，可单独保存或放到 GitHub 中。PNG、SVG、逐实验 CSV 和全部最终 Q 表也单独保留。

默认运行共 **176 次独立训练**：基准 40 次，4 个其他折现因子各 16 次，3×3 学习参数网格各 8 次。δ=0.95 的折现因子对照直接复用基准，网格中心点则是另外的独立种子。

扩大重复次数：

```sh
python t3/src/replicate.py --sessions 100 --sensitivity-sessions 40 --grid-sessions 20
```

参数：`--max-steps` 默认 5,000,000；`--seed` 默认 20261024，必须为正。修改重复次数或种子会覆盖同名结果；运行时仅按当前记录评估，不会读入旧的额外 Q 文件。若从更多次数降为更少次数，raw 目录可能保留旧文件，分享时应以各组 sessions.csv 的记录为准。

## 模型

- 两家企业同时定价，单位成本 c=1，质量 a=2，外部产品 a₀=0，Logit 差异化系数 μ=0.25。
- 连续价格竞争均衡 pᴺ≈1.472927，联合垄断价格 pᴹ≈1.924981。
- 15 个价格，均匀覆盖 `[pᴺ−0.1(pᴹ−pᴺ), pᴹ+0.1(pᴹ−pᴺ)]`。
- 状态为上一期两家的价格索引，225 个状态；每家 Q 表形状为 225×15。
- 原文代表性参数 α=0.15、β=4×10⁻⁶、δ=0.95，探索概率 exp(−βt)。t 从 0 开始。
- 初始化 Q 为对手均匀随机定价时的单期预期利润除以 1−δ；初始状态均匀抽取。
- 每期双方先依据各自 Q 表同时选动作，再观察双方价格及利润，更新各自被访问的一个 Q 单元；相同 Q 值选择最低价格。
- 全状态贪心策略连续 100,000 期不变视为达到论文稳定判据；它不是一般意义下的均衡证明。每次最多 5,000,000 期。

市场和价格基准在 Python 中求解。C++ 仅加速大量逐期更新，Python 完成实验组织、后评估、图表和 HTML。没有把论文的方法换成其他深度强化学习算法。

## 评价与偏离分析

标准化利润增益 `Δ=(π−πᴺ)/(πᴹ−πᴺ)`；π 是两家企业的周期平均单企业利润。它不是价格涨幅。连续竞争价格不一定在离散网格上，因此 Δ=0 不是对网格均衡的精确表述。

学习完成后，冻结 Q 表、关闭探索，从停止时的状态沿贪心策略前进，剔除瞬态并识别完整周期。长期价格和利润按周期平均，不是选取单个较高价格。

偏离实验对周期每个相位各做一次：第 1 期强迫企业 1 采取针对对手当期原定价格的网格内静态最佳反应；随后双方恢复所学策略。第 0 期显示状态所记忆的前期价格。先按同一实验的周期相位平均，再跨实验平均，避免长周期实验获得更高权重。反事实从同一个状态出发，全程无强制偏离。

偏离是否有利按企业 1 从偏离期起 400 期折现利润差计算。δ=0.95 的尾项因子约 1.2×10⁻⁹；这是有限截断近似。“不利偏离比例”先在每次实验内部按周期相位计算，再对实验平均。它只覆盖特定的一期偏离及在轨周期相位，不是检验了所有状态、所有动作的完整均衡分析。

## 验证

`src/verify.py` 包括：

1. 连续市场基准、收益对称性、价格网格排序。
2. 实际 C++ 更新循环与独立 NumPy 实现，在 300 次确定动作后对两家全部 6,750 个 Q 值做严格数值比较。后端 seed=0 专用于此测试，正式实验禁止 seed=0。
3. 同一随机种子重复运行的输出及 Q 表逐字节一致。
4. 每次基准实验重新识别周期并复算报告利润。
5. 各周期相位的强制偏离确为网格内静态最佳反应。
6. 实验轮数上限、停止判据所需最短时间及数值有限性。

## 与完整论文复现的差别

保留原文的核心经济环境、学习方法和稳定判据；减少重复次数、折现因子取点和学习参数网格，将原文十亿轮上限降为五百万轮。不同随机数生成器与种子也会产生不同样本路径。当前基准结果与论文量级接近，不应解读为精确复现全样本数字。

误差线是独立实验均值的 1.96×标准误，重复次数较少时仅作探索性展示。学习曲线的较晚窗口只有未停止实验参与，下方明确绘制样本数；尾部变化包含样本构成变化，不能直接解释为同一组算法的行为变化。

尚未实现完整最优响应与 Q-loss 均衡检验、多人竞争、非对称成本或需求、不确定性、重新配对与全套稳健性实验。价格偏高本身不足以证明合谋，报告将价格结果、惩罚反应及有限的激励检查分开呈现。
