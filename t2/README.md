## 库存时序和成本

每期先接收 L 期前的订单。整批合格概率为 p，失败概率 1−p；失败不收采购费，也不产生库存。期初接收后净库存记 I_t，尚未到货的 L−1 笔订单组成状态，随后决定 q_t。发生需求后，正库存支付持有费，负库存作为积压并支付缺货费，不清零。采购成本仅在合格到货时收取。初始库存和所有在途订单为零，第一笔订单在第 L+1 期到达，最后 L 期停止下单。所有成本按折现因子 α 的 t−1 次方折现。

连续需求案例不对订货量取整，也没有人为订货上限。

## 四种策略

1. **LIR**：`max(S_L − I − p×在途订单总量, 0)`。遵循本文设定，膨胀因子 β=1，而不是 1/p。
2. **WNH**：枚举 `2^(L−1)` 个在途供货成败组合。各组合计算非负库存缺口，以独立伯努利组合概率加权。所有组合都保留，不用期望到货替代枚举。
3. **GDSH**：沿用 WNH 的缺口基函数，学习一组状态无关权重，目标为平均折现成本。权重从 WNH 初始化，不强制和为 1。
4. **DRL**：隐藏层 `[8,16,16]`、ReLU；增强状态 `(S_L,I,在途订单)` 为输入，每种成败组合输出两个 logits，经行 Softmax 映射到 `[w_WNH−δ,w_WNH+δ]`。L=2 时 δ=0.25，L=5 时 δ=0.0884。不是跨组合 Softmax，也不是通用 PPO/DQN。

网络输入除以 S_L，末层零初始化，使初始策略与 WNH 完全一致。权重允许负值（论文区间本来可能为负），但最终订货量必须非负，因此组合后再施加 ReLU。GDSH 权重同样不裁剪为概率。

使用 Adam，初始学习率 0.003，每 epoch 乘 0.98，下限 0.0001。梯度经完整库存与在途订单路径反向传播，不把未来库存当成与当前决策无关的常量；梯度范数上限为 10。

S_L 按论文公式 (3) 计算，需求参数采用模拟分布的已知参数。正态需求小于 0 时截为 0，但 S_L 使用截断前的均值、方差。伽马分布均值 10、scale=1.6，形状为 10/1.6。公式的供货风险项要求 p>0.5，本实验所有案例均满足。

## 损失函数与排名差异

主 DRL 逐轨迹构造 `r=100×(C_DRL−C_WNH)/C_WNH`，最小化 `log(mean(exp(r)))`。对数为严格单调变换，与平均指数损失具有相同的最小点；但 Adam 的有限步优化轨迹未必与直接使用指数值完全相同。采用 log-sum-exp 避免数值溢出，没有直接裁掉高损失样本。

这类目标会对某些相对表现很差的轨迹赋较大权重，未必与最小化平均成本相同。GDSH 直接优化平均成本。因此若主结果显示 GDSH 优于 DRL，不能删除这个结果或宣称已复现 DRL 最佳排名。

论文未附作者聚合代码，额外诊断“先算批量平均成本、再算相对指数损失”的版本，计算上最小化其对数，即 `100×(mean(C_DRL)−mean(C_WNH))/mean(C_WNH)`；它等价于批量平均成本优化。主图、主表仍使用逐轨迹指数目标。辅助版本不是对作者实现的断言，也不是为了逼近原表而替换模型。

## 实验网格

12 个核心案例：L∈{2,5}，p∈{0.6,0.8,0.95}，需求∈{正态、伽马}，T=50、b/(b+h)=0.9、μ=10、采购成本 2、持有成本 1、折现因子 0.99。

另外 6 例：在正态需求、p=0.8 下，每个 L 加入临界比例 0.85、0.95 及 T=100。原论文大规模实验为 432 例，这里仅保留代表性参数。总体平均先对每例的平均成本等权平均，再计算相对 LIR 的百分比。

测试区间基于同一路径的“模型−LIR”成本差，半宽为 1.96×标准误，仅反映路径采样误差；不包含单训练种子带来的模型不确定性。每个案例训练、验证、测试使用不同的随机数流，测试从不参与梯度或检查点选择。

## 小规模 DP

明确采用另一个可精确计算的离散模型：T=8、L=2，D∈{1,2,3}，概率 (0.25,0.5,0.25)，p∈{0.7,0.8,0.9}，整数订货量 0 到 12，折现因子 0.95、采购费 2、持有费 1、缺货费 9。

DP 枚举可行动作与需求/供货结果，使用记忆化有限时域递推。没有库存边界截断或插值；从初始状态实际可达的状态均计算。在该动作和需求支持下是精确最优，但不是原文连续正态需求模型的全局最优。

四种策略均采用相同的取整与上限。网络在此离散模型单独训练，取整采用直通梯度估计器；评价则对这些离散策略递推精确期望，避免因蒙特卡洛误差看似低于 DP。DP 递推将下一期成功到货的采购费计入下一期折现，符合到货付款。

## 验证与限制

- 手算确认 L=2 的到货时点、整批失败、最后 L 期停止下单、采购费与积压成本。
- WNH 与独立穷举公式比较；初始 GDSH/DRL 与 WNH 相等；权重区间与组合完整性核验。
- PyTorch 可微库存过程与独立 NumPy 队列实现交叉核对。
- T=3、L=2 的 DP 与全部需求及供货情景穷举结果核对。
- 保存模型重载后，重新生成测试集并核对逐路径成本。
- 所有成本分解相加一致；同一个受限离散模型中策略成本不得低于 DP。

没有作者源码，因此网络初始化、状态尺度、批量聚合、非负行动处理及验证选择属于明确记录的实现约定。没有复现所有 432/972 个案例、全部训练种子、长提前期 DP、批量订货和非 IID 需求扩展。有限案例中的差距应如实报告，不能把“能训练运行”说成“精确复现全部结论”。

## 本次运行结果

默认 18 例等权平均折现成本：LIR 3043.76，WNH 3020.90，GDSH 2945.93，主 DRL 3008.52；相对 LIR 分别降低 0%、0.75%、3.21%、1.16%。主 DRL 没有超过 GDSH，因此论文“DRL 平均表现最佳”的结论在当前实现和缩减样本中未完全复现。

三个离散案例的主 DRL 相对 DP 差距为 3.65%、2.80%、0.95%；GDSH 为 3.01%、2.51%、0.91%。这些数字属于受限离散小模型。

两个辅助聚合实验（正态需求、p=0.8）的 batch-mean 版本相对 LIR 降低约 1.83%（L=2）与 5.00%（L=5）。辅助结果不与 18 例总体指标直接比较，不替换主结果。

主训练、评估和 DP 总计约 286.6 秒，辅助聚合诊断另行计时。完整核验通过；六张图已逐张检查。
