04 / 真实训练与检查点

网络隐藏层为 [8,16,16]，ReLU；每条供货组合输出两个 logits，经行 Softmax 映射到 WNH 权重 ±δ。δ 在 L=2 时为 0.25，L=5 时为 0.0884。权重不是在全部组合上归一化的概率。网络末层零初始化，使初始策略严格等于 WNH；输入除以 S_L，属于本实现的数值稳定处理。

DRL 使用论文的 exp(100×(C_DRL−C_WNH)/C_WNH) 轨迹相对损失，计算时以 log-mean-exp 等价单调变换避免溢出；梯度经完整库存路径反向传播。GDSH 直接优化样本平均折现成本，权重不随状态变化。Adam 初始学习率 0.003，每 epoch 乘 0.98、下限 0.0001；梯度范数上限 10 为本实现稳定措施。

每 10 epoch 在独立验证集选择平均成本最低的检查点，包含初始 WNH 候选。共 36 个连续需求模型，其中 0 个保留初始检查点；这是公开的验证选择，不是依据测试结果替换策略。完整训练历史和模型权重已保存。

08 / 运行与复现边界

python -m pip install -r t2/requirements.txt

Python + PyTorch 在 CPU 上训练，无需外部数据、API 或 GPU。HTML 内嵌图片，可离线查看；各图另存 PNG/SVG，模型在 models/，逐路径成本、训练历史、配置与审计数据均保存。

主要实现约定：对权重组合得到的订货量施加非负约束，GDSH 权重自由优化但行动仍非负；权重区间本身可含负数，未擅自将其裁剪成概率。S_L 使用已知模拟分布的参数；正态需求在 0 截断但计算 S_L 使用截断前参数。不同于原文最后 epoch 的做法，本版使用验证集检查点；这些改动及有限实例与单种子限制详见 README。
