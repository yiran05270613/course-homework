算法如何学会定价？

独立 Q-learning · 超竞争价格 · 偏离后的反应

基于论文公式自行实现，所有结果均来自本次模拟。未使用论文图表数据作为复现结果。

01 / 实验设定与结果概览

两家企业，Logit 需求，成本 c=1、产品质量 a=2、外部选项 a₀=0、μ=0.25。15 个离散价格，记忆上一期双方价格：225 个状态，每家 Q 表 225×15。折现因子 δ=0.95，学习率 α=0.15，探索率 εₜ=exp(−4×10⁻⁶t)。采用原文 Q 初始化及全状态策略稳定 100,000 期的停止条件。

02 / 学习过程 · 对应图 10 的思路

每条实验按 5,000 期窗口汇总后跨实验平均，不是论文原图的 100 期移动平均。提前停止后不补造训练数据，下方同步显示参与样本数：后段均值会受样本退出影响，不能把尾部下降直接解释为同一组算法降低价格，详见 learning_summary.csv。

03 / 偏离、惩罚与恢复 · 对应图 4 的思路

训练停止后冻结 Q 表并关闭探索，先找到贪心策略的最终周期。对每个周期相位，在第 1 期强制企业 1 采用针对对手原定价格的网格内静态最佳反应，之后双方恢复所学策略。先对周期相位平均，再对独立实验平均。虚线反事实控制周期本身引起的价格变化；阴影为跨实验均值的近似 95% 区间。

按各周期相位计算，偏离折现净收益不为正的平均比例为 97.5%；平均偏离净收益为 -0.180217。折现比较累计 400 期，δ=0.95 时尾项很小。它只检验一种单期偏离，不等同于对所有状态和所有策略证明纳什均衡；也没有预设必须出现惩罚。

07 / 复现边界与运行

保留核心经济环境、Q 更新、最低价格打破平局、原文初始化、探索递减和稳定停止条件。缩减独立重复次数与参数网格，并将原文十亿期上限降为 5,000,000 期。当前未复现均衡最优响应完整检验、多人企业、非对称环境、需求不确定性、重新配对及全部稳健性实验。

python -m pip install -r t3/requirements.txt

需要 Python 3.13 及 C++17 编译器。Python 负责市场求解、实验组织、统计与图表；C++ 负责大量逐期 Q 更新以缩短计算时间。所有代码和原始 Q 表保存在项目内，运行不需要联网。详见 README.md。
