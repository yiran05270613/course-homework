从预测到库存决策

端到端库存管理 · 可重复计算的学习报告

本页所有“复现”数字来自本地 CSV 的实际计算；E2E 和 GBM 使用作者提供的预测，未重新训练神经网络。

01 / 数据与复现范围

离线数据 3,000 条记录，实际 2,607 个唯一 SKU 标识。现场实验四组各 500 条记录。控制候选 55,333 条。计算耗时 1.08 秒（不含安装依赖与开发）。

固定 h=1，b=9。公开材料是抽样数据，不能期望与原论文全样本数值完全一致。原论文图 1 是网络结构示意图，本项目不将结构重绘冒充模型训练复现。

审计发现 37 个 SKU 没有到货后可评估点，按作者代码其成本计为零并进入均值。该现象以及 77 次备用库存引用（跨七种方法计数）保留在主复现，不能视作完善的生产级模拟。主结果严格沿用作者 Notebook：仅统计每段预测到货时点及之后的库存。完整生成序列成本另见 offline_summary.csv 的 full_generated 行；这仍是作者模拟器的口径对照，不是另行实现的完整库存模型。

BM1/BM2 使用公开 sf_rnn 的均值构造；原论文还涉及多分位数预测选择，当前数据无法独立恢复全部候选模型。Normal 保留作者代码的 1.64 系数与方差公式，Gamma 使用 0.9 分位数。OPT 为公开文件中的离线最优预测参考，不代表我们重新求解并验证了全局最优。

08 / 如何重新运行

python -m venv .venv
source .venv/bin/activate
python -m pip install -r t1/requirements.txt
python t1/src/replicate.py

输出：t1/results/index.html、逐样本计算、汇总 CSV、匹配索引与审计 JSON。可以离线打开本页；无 CDN、在线字体或远程脚本依赖。

方法与限制详见 README.md。源文献 DOI：10.1287/mnsc.2022.4564。
